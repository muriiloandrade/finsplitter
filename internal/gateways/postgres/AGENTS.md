# PostgreSQL Gateway — pgx pool, sqlc queries, migrations, transactions

**Purpose**: The only package that talks to PostgreSQL: pgx v5 connection pool, type-safe sqlc queries, versioned golang-migrate migrations, the `TxManager` transaction abstraction, and repository implementations mapping rows to domain entities. No business logic; use cases depend on ports interfaces.

## Ownership

- `pool.go` — `NewPoolConfig`: pgxpool config from `config.Database`; `AfterConnect` registers type adapters; otelpgx tracer; pool sizing
- `builder.go` — shared squirrel `psql` builder (Dollar placeholders) for dynamic queries
- `tx.go` — `TxManager` (`WithTx`, `querier`, `Exec/Query/QueryRow/SendBatch`, `Close`) — satisfies `domain.Transactioner`
- `card_brand.go`, `user.go` — repository implementations (sqlc rows → entities, DB errors → domain errs)
- `sqlc/` — GENERATED code (`db.go`, `models.go`, `*.sql.go`) — never hand-edit
- `sqlc/queries/*.sql` — source SQL with `:one`/`:many` annotations (currently `card_brand.sql`, `user.sql`)
- `migrations/` — timestamped `.up.sql`/`.down.sql` pairs + `migrate.go` (`RunMigrations`, golang-migrate v4 pgx driver)
- `testutils/postgres.go` — testcontainers-go v0.44.0 integration-test helper
- NOT: entities/errors/transactioner contracts (`internal/domain/`), repo interfaces (`internal/app/ports/`), business logic (`internal/app/usecases/`)

## Local Contracts

- **Connection**: pgx v5 `pgxpool`; DSN built in `NewPoolConfig` with `sslmode` from `PG_SSL_MODE` (require in prod), `application_name=finsplitter`, pool params from `config.Database.Pool`.
- **Type adapters** registered `AfterConnect`: `pgxuuid.Register` (gofrs/uuid/v5 ↔ `uuid`) and `pgxdecimal.Register` (shopspring/decimal ↔ `numeric`); `otelpgx.NewTracer(otelpgx.WithIncludeQueryParameters())` for spans.
- **sqlc**: queries in `sqlc/queries/*.sql` annotated `-- name: X :one` (single row) / `:many` (rows); optional args via `sqlc.narg(...)`; run `make generate-sqlc` after every query change; generated files are read-only (`Code generated by sqlc. DO NOT EDIT.`).
- **Dynamic queries**: squirrel builder for optional filters (see `ListCardBrands` — pagination + optional `id`/`name` ILIKE). Still parameterized — never concatenate user input into SQL.
- **Error mapping**: `errors.As(err, &pgErr)` + `pgerrcode.IsIntegrityConstraintViolation(pgErr.Code)` → domain errs by code (`UniqueViolation` → e.g. `errs.ErrCardBrandAlreadyExists`, `ForeignKeyViolation` → `errs.ErrCardBrandForeignKeyViolation`, else `errs.ErrDatabaseGeneric`); `errors.Is(err, pgx.ErrNoRows)` → `errs.ErrNotFound`/`errs.ErrCardBrandNotFound`. Never leak SQL details to callers.
- **Transactions**: use cases call `TxManager.WithTx(ctx, fn)` (the `domain.Transactioner` contract). Nested `WithTx` → error (guarded by `domain.HasTX`); rollback on panic; `querier(ctx)` returns the active `*pgxpool.Tx` when present, else the pool. Repositories never call `Begin` themselves.
- **Migrations**: golang-migrate v4 with the pgx driver; timestamped `{version}_{name}.up.sql` / `.down.sql` pairs created by `make new-migration name=<name>`; `RunMigrations` treats `migrate.ErrNoChange` as success; never edit applied migrations.
- **Key schema constraints** (see migrations; business rules in `project-intelligence/business-domain.md`):

| Table | Constraint | Description |
|-------|-----------|-------------|
| `user` | `UNIQUE(lower(email))` | Case-insensitive unique emails |
| `user` | `UNIQUE(lower(username))` | Case-insensitive unique usernames |
| `card_brand` | `UNIQUE(lower(name))` | Case-insensitive unique brand names |
| `bill` | `UNIQUE(card_id, year, month)` | One bill per card per month (BILL-001) |
| `card.l4d` | `CHECK(l4d ~ '^[0-9]{4}$')` | Exactly 4 numeric digits |
| `transaction.value` | `CHECK(value != 0)` | Non-zero transaction values (TXN-001) |
| `*_percentage` | `CHECK(0 <= percentage <= 100)` | Valid percentage range (SPLIT-001) |
- **Timestamps/UUIDs**: entities carry `created_date` + `last_modified_date`; `last_modified_date` is auto-updated by the `set_last_modified` trigger (new tables need their own trigger migration); entity IDs are `gofrs/uuid/v5` with uuidv7 defaults.
- **Integration tests**: `testutils.NewTestDB(t)` starts `postgres:18.4-trixie`, runs migrations, auto-cleans on test end; skips under `-short`; `StartTestDB` for manual control.

## Work Guidance

1. New table/feature: `make new-migration name=create_table_foo` → SQL in `sqlc/queries/foo.sql` → `make generate-sqlc` → entity in `internal/domain/entity/` → port in `internal/app/ports/` → repo in `internal/gateways/postgres/foo.go` → wire in `cmd/api/main.go` → `make generate-mocks` + tests.
2. Query pattern (`:one` for single row, `:many` for lists):

```sql
-- name: CreateCardBrand :one
INSERT INTO card_brand (name) VALUES ($1) RETURNING *;
```

3. Repo methods: log via `logctx.FromCtx(ctx)` with an `op` const; map sqlc errors per the error-mapping contract; parse generated rows to entities (`parseToCardBrand` pattern).
4. Indexing: add indexes for columns in WHERE/JOIN/UNIQUE paths; use partial indexes for filtered subsets:

```sql
CREATE INDEX idx_card_brand_name ON card_brand(name);
CREATE INDEX idx_active_users ON users(id) WHERE status = 'active';
```
